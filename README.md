# Atacama Dev Web

Atacama Dev es una agencia orientada al desarrollo web y creación de software a medida. Nuestro objetivo es llevar las ideas al siguiente nivel utilizando tecnología moderna, optimización SEO y una experiencia de usuario (UX/UI) cuidada al detalle.

## Stack Tecnológico

El proyecto está construido bajo los siguientes cimientos modernos:

- **Librería UI:** React 19
- **Empaquetador y Entorno de Desarrollo:** Vite
- **Animaciones y Efectos:** GSAP (GreenSock Animation Platform)
- **Lenguaje Principal:** JavaScript / JSX
- **Estilos:** CSS moderno (variables, flexbox, grid, animaciones nativas)

## Estructura de Carpetas

La arquitectura del proyecto está pensada para ser escalable y de fácil mantenimiento:

```text
Atacama Dev web/
├── public/                 # Archivos estáticos servidos directamente al usuario
│   ├── favicon_io/         # Iconos de la pestaña del navegador y manifest
│   ├── projects/           # Recursos visuales del portafolio (imágenes)
│   └── screenshot-ad.png   # Previsualización principal (Open Graph/SEO)
├── src/                    # Código fuente principal de la aplicación React
│   ├── components/         # Componentes modulares y reutilizables
│   ├── styles/             # Archivos CSS globales y utilidades
│   ├── App.jsx             # Punto de entrada de enrutamiento y estructura
│   └── main.jsx            # Configuración de renderizado de React DOM
├── index.html              # Plantilla base y metadatos SEO/Open Graph
├── package.json            # Dependencias, scripts y configuración del proyecto
└── vite.config.js          # Configuración del servidor y build de Vite
```

## Características Destacadas

1. **SEO Optimizado:** Integración de metadatos profundos (Open Graph y Twitter Cards) para previsualizaciones impecables al compartir el enlace.
2. **Animaciones Dinámicas:** Transiciones fluidas y profesionales en la interfaz utilizando el poder de GSAP.
3. **Responsive Design:** La web se adapta perfectamente desde dispositivos móviles a pantallas extra grandes.
